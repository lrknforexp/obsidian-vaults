## Where to Begin

> [!info] Complete Beginner? Start Here.
> If you have never written a single line of code, follow this exact order:
> 1. Read [[Beginner Stage]] — understand the mindset and setup
> 2. Start with **[[HTML]]** — the simplest language; you see results instantly
> 3. Move to **[[CSS]]** — make things look good
> 4. Then **[[JavaScript (JS)]]** — make things interactive
> 5. Then **[[Python]]** — learn real programming logic
> 6. Then return to this index and pick your path

## The Learning Stack (What Order to Learn)

### Path A — Web Developer (Most Popular)
```
HTML → CSS → JavaScript → React → Node.js → SQL → TypeScript
```

### Path B — Python / Data / AI Developer
```
Python → SQL → Git → Python Libraries (NumPy, Pandas) → Machine Learning
```

### Path C — General Software Engineer
```
Python or Java → Data Structures & Algorithms → SQL → Git → System Design
```

> [!info] Golden Rules of Learning to Code
> 1. **Type every example yourself** — never copy-paste while learning
> 2. **Break things on purpose** — error messages teach you more than success
> 3. **Build projects** — tutorials alone won't make you a coder
> 4. **Be consistent** — 30 minutes daily beats 5 hours once a week
> 5. **Google everything** — professional developers search Stack Overflow constantly
