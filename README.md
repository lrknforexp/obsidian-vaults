---

## 💾 Backup Workflow

Using **GitHub Desktop** to keep everything synced:

1. Take notes in Obsidian as usual
2. Open GitHub Desktop
3. Review changed files
4. Add a summary (e.g. `Add history notes week 3`)
5. **Commit to main** → **Push origin**

---

## 🚫 Ignored Files

Local Obsidian cache files are excluded to keep the repo clean:

```
.obsidian/workspace.json
.obsidian/workspace-mobile.json
.obsidian/cache
.trash/
```

---

## 🔄 Restoring on a New Device

1. Clone this repo via GitHub Desktop or:
   ```bash
   git clone https://github.com/lrknforexp/obsidian-vaults.git
   ```
2. Open **Obsidian** → **Open folder as vault**
3. Select the folder you want to open
